# 경제 데이터베이스 및 거시·국제 통계 인프라

## 데이터 분석의 윤리와 기초 — 접근·활용 전략

데이터가 있다는 걸 아는 것과 실제로 손에 넣는 건 다른 얘기임. 데이터의 민감도·보안 수준에 따라 접근 경로가 갈리니까, 연구 설계 단계에서 같이 정하고 들어가야 함.

### 공개 데이터(Public Use Microdata) 접근

대부분의 설문은 개인 식별 정보를 뺀 **PUMD(Public Use Microdata)** 형태로 무료 제공됨.

- **IPUMS (Integrated Public Use Microdata Series):** 미네소타대가 운영하는데, 데이터 접근의 '게임 체인저'라고 부를 만함. CPS·ACS·국제 센서스의 변수명과 코딩 체계를 연도별로 일관되게 **조화(harmonization)**시켜 줘서, 원하는 변수·연도만 골라 맞춤 데이터셋을 만들 수 있음. SAS·Stata·R용 읽기 스크립트(syntax)도 자동으로 줌. 시계열 분석을 할 거면 원본 사이트보다 IPUMS가 압도적으로 효율적임.
- **ICPSR:** 미시간대의 거대한 사회과학 데이터 아카이브(PSID·Add Health 등). 다운로드 외에 변수 검색·온라인 분석 도구도 제공함.

### 제한적 접근 데이터(Restricted-Use)와 FSRDC

기업의 상세 재무, 개인 주소지가 포함된 정밀 데이터, 사망 원인 같은 민감 정보는 공개되지 않음.

- **연방통계데이터센터(FSRDC):** 이런 데이터는 연구계획서를 내서 승인받은 뒤, 보안이 철저한 물리적 공간인 FSRDC 안에서만 분석할 수 있음. 결과물도 엄격한 **반출 심사(Disclosure Review)**를 거쳐 개인 식별 가능성이 없음을 확인받아야 밖으로 가지고 나올 수 있음. 행정 데이터와 설문 데이터를 결합하는 고난도 연구엔 필수 절차임.

### 소프트웨어 호환성

대부분의 제공 기관(NBER·BLS·IPUMS 등)은 SAS·Stata·R 형식을 다 지원하거나, CSV/ASCII와 함께 읽기 스크립트를 줌. 최근엔 대용량 데이터(ACS 전체 표본, 닐슨 등) 처리에 Python·R의 고성능 패키지(예: R의 `srvyr`) 사용이 느는 추세지만, 계량 분야에선 여전히 Stata·SAS가 표준임. 특히 복잡한 **가중치(weighting)** 적용과 **표준오차 보정**은 Stata·SAS가 강점을 가짐.

---

미시 데이터가 경제라는 '숲'의 '나무'를 본다면, 거시·국제 데이터베이스는 숲 전체의 생태와 기후를 조망하게 해줌.

## FRED (Federal Reserve Economic Data)

세인트루이스 연은이 운영하는 FRED는 전 세계 경제학자가 가장 신뢰하고 자주 쓰는 시계열 플랫폼임. 80만 개 넘는 변수를 주고, 단순 저장소를 넘어 분석 도구 기능까지 갖췄음.

- **ALFRED (Archival FRED):** 경제 지표는 수정(revision)이 잦음. ALFRED는 특정 시점에 발표됐던 과거 수치(**vintage data**)를 그대로 보존해서, "당시 정책결정자가 어떤 데이터를 보고 판단했는지"를 복원하는 연구를 가능케 함.
- **API 연동:** R·Python·Excel과 강력하게 연동돼서, 코드로 실시간 업데이트하고 분석 모델에 바로 주입할 수 있음.

## 국제 비교용 데이터 — PWT, Maddison, Barro-Lee

국가 간 성장 격차를 보는 거시경제학자한텐 이 셋이 거의 필수임.

- **Penn World Table (PWT):** 180개국 이상의 GDP·자본스톡·고용·생산성을 1950년부터 제공. 핵심은 시장환율이 아니라 **구매력평가(PPP) 환율**로 국가 간 실질 생활수준·생산능력을 비교한다는 것. 이게 **'펜 효과(Penn Effect)'**(고소득국일수록 물가가 높아 시장환율로 GDP를 환산하면 과대평가되는 현상)를 교정해 줌.
- **Maddison Project Database:** 故 앵거스 매디슨 교수의 작업을 이어, 서기 1년부터 현재까지의 초장기 세계 경제통계를 제공. 산업혁명 이전 성장과 장기 경제사 연구엔 대체 불가. 2020년 업데이트는 PWT 최신 방법론과 역사학적 고증 사이 균형을 맞췄음.
- **Barro-Lee Educational Attainment:** 로버트 배로와 이종화 교수가 구축. 1950년부터 5년 단위로 146개국의 성별·연령별 교육 이수 연수와 단계별 이수율을 줌. 성장 회귀분석(growth regression)에서 **인적자본(human capital)** 대리변수로 가장 널리 쓰이는 표준 데이터고, 최근엔 센서스 보강으로 정확도를 높였음.

## NBER 데이터 라이브러리

NBER은 단순한 연구소를 넘어 데이터 허브 역할을 함.

- **NBER-CES Manufacturing Industry Database:** 1958~2018년 미국 제조업의 총요소생산성(TFP)·산출·노동비용·투자를 6자리 NAICS 코드로 세분화해 제공. 기술 변화·무역 충격이 산업 생산성에 미치는 영향을 보는 미시 생산성 연구의 기초.
- **특허 데이터(Patent Data Project):** USPTO 데이터를 가공해 기업의 혁신 활동과 지식 전파(knowledge spillovers)를 추적할 수 있게 함.
- **거시경제사 데이터:** 대공황 이전의 초기 거시 지표를 복원해 장기 경기변동 연구를 지원함.

## Opportunity Insights와 행정 데이터의 혁명

Raj Chetty 교수팀의 Opportunity Insights는 데이터 혁명의 상징 같은 프로젝트임. 익명화된 수천만 건의 국세청(IRS) 세금 기록을 인구센서스와 결합해, 미국 전역의 모든 인구조사구(census tract) 단위에서 세대 간 이동성 지표를 산출했음.

- **Opportunity Atlas:** "어떤 동네에서 자라는가"가 성인기 소득·수감률·십대 출산율에 미치는 인과적 효과를 시각적으로 확인하고 다운로드할 수 있는 플랫폼. 설문의 표본 크기 제약 때문에 불가능했던 **동네 효과(Neighborhood Effects)**의 정밀 분석을 가능케 했음.

## 고빈도(High-Frequency) 민간 데이터 — '나우캐스팅'의 시대

코로나19 팬데믹이 경제 충격을 실시간으로 추적할 필요를 폭발시켰고, 그게 민간 데이터의 학술적 활용을 가속했음.

- **신용카드 거래 데이터:** Affinity Solutions·First Data 같은 결제 처리 기업이 익명화된 거래 데이터를 연구자에게 제공함. 월간/분기 통계의 시차 없이, 특정 정책(예: 재난지원금) 지급 직후의 소비 반응을 **일별**로 추적할 수 있게 해줌.
- **위치·이동성 데이터 (SafeGraph):** 스마트폰 GPS로 특정 장소(POI) 방문자 수를 집계함. 팬데믹 동안 사회적 거리두기 준수와 경제 활동 위축을 측정하는 데 널리 쓰였고, Dewey Data 플랫폼으로 학계가 저렴하게 접근할 길이 열려 있음.
- **소매 스캐너·소비자 패널 (Nielsen):** 시카고대 Kilts Center로 제공되는 닐슨 데이터는 둘로 나뉨 — **소매 스캐너(Retail Scanner)**는 마트 POS에서 집계한 주별·품목별 판매량·가격, **소비자 패널(Consumer Panel)**은 6만 가구가 직접 바코드를 스캔해 기록한 구매 내역. 가격 탄력성·신제품 도입 효과·가계의 인플레이션 체감도 같은 걸 미시적으로 보는 산업조직론·거시 연구에 필수임.
